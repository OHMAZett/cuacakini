Keamanan & Privasi Publik

Tanpa Pelacakan Data Pribadi

Aplikasi ini tidak melacak, tidak menyimpan cookies pihak ketiga, dan tidak menjual data riwayat pencarian Anda ke siapapun.

Privasi Geolocation Transparan

Izin GPS Anda hanya digunakan sekali di browser Anda untuk mencari nama kota terdekat. Koordinat tidak pernah disimpan di server kami.

Proteksi Sanitasi Input XSS

Setiap kata kunci pencarian melewati sanitasi ketat untuk mencegah serangan Cross-Site Scripting (XSS) dan injeksi kode berbahaya.

Koneksi API Terenkripsi (HTTPS / WMO Standard)

Seluruh komunikasi prakiraan cuaca diambil secara aman via protokol SSL/TLS terenkripsi menggunakan layanan publik terbuka Open-Meteo tanpa API Key rahasia.
